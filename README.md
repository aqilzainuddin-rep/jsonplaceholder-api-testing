# JSONPlaceholder API Automation

Five independent API automation projects exercise the same JSONPlaceholder endpoints.

| Project | Toolchain |
|---|---|
| python-pytest | Python, Requests, pytest |
| java-testng | Java, REST Assured, TestNG |
| java-junit5 | Java, REST Assured, JUnit 5 |
| javascript-vitest | JavaScript, Axios, Vitest |
| typescript-playwright-api | TypeScript, Playwright APIRequestContext |

Each project progresses from direct API calls to reporting and CI. Checkpoint commits
record that progression. The API simulates writes and keeps its original sample data.
